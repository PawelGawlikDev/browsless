# Browsless

Local-first Chrome extension for browser automation, built with `WXT`, `Vue 3`, `TypeScript`, and `Tailwind CSS v4`.

## Commands

- `pnpm dev` - start WXT dev mode
- `pnpm build` - build the extension for Chrome MV3
- `pnpm zip` - create a zip archive
- `pnpm typecheck` - run `vue-tsc --noEmit`

## Structure

- `src/` - application source
- `entrypoints/` - WXT entrypoints
- `public/` - static assets copied as-is
- `docs/` - development docs for repo structure and styling
